# SentinelForge X

SentinelForge X is an explainable and testable detection engineering platform
for investigating security events from Windows, Linux and network telemetry.

The project is designed around a practical security operations problem:

> How can analysts determine why a detection fired, measure whether it is
> reliable, reproduce an investigation and communicate the result clearly?

## Project goals

- Normalise security events from multiple sources
- Create version-controlled detection rules
- Explain exactly why an alert was generated
- Correlate related events into incidents
- Replay incidents reproducibly
- Measure detection quality and false positives
- Map detections to MITRE ATT&CK
- Generate evidence-backed incident reports
- Provide a secure, reproducible development environment

## Planned capabilities

- Event ingestion and normalisation
- Detection-as-code
- Explainable alert generation
- Incident timelines
- Detection replay
- Precision, recall and false-positive analysis
- MITRE ATT&CK mapping
- Case management
- Security automation
- Automated testing
- CI security checks

## Status

Project initialisation.

## Safety and ethics

All testing will be performed only on systems and data owned by the author or
specifically provided for authorised testing.

No public websites, third-party networks or unauthorised systems will be
scanned, attacked or tested.
